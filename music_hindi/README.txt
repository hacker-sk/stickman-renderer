Put your background music files for the Hindi videos in this folder (mp3, wav, m4a or ogg).
One random file is used for each video.
Optional: name a file like calm-song.mp3, emotional-song.mp3, inspiring-song.mp3, mysterious-song.mp3, dramatic-song.mp3 or upbeat-song.mp3 and it will be used for videos with that mood.
You can delete this README after adding music.
